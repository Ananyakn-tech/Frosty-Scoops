# Frosty Scoops
 
A web-based ice cream e-commerce application built with PHP, MySQL, HTML, CSS, and JavaScript.
 
## Features
 
- User registration and login with session management
- Categorized menu (Scoops, Sundaes, Shakes & Specials)
- Shopping cart with quantity controls and subtotals
- Live search and hover effects
- Checkout with COD, UPI, and Card payment options
- GST + delivery charge calculation
- Order placement and cart clearance on success
## Tech Stack
 
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP (Apache + MySQL)
## Setup
 
1. Clone the repo into your XAMPP `htdocs` folder
2. Start Apache and MySQL in XAMPP
3. Import `database.sql` in phpMyAdmin
4. Open `http://localhost/frosty_scoops/login.php` in your browser
